# Mở bản thiết kế Figma

1. Tại trang GitHub CIV-01, chọn **Code → Download ZIP** rồi giải nén. Các tệp `.fig` nằm trong thư mục `04_Giao_dien_Figma`, đặt tên theo số hình và mã màn hình F01–F20.
2. Đăng nhập [Figma](https://www.figma.com/) trên máy tính. Về trang danh sách tệp và mở **Drafts**.
3. Chọn **Create new → Import → Import from computer**. Chọn tệp `.fig` đã tải, bấm **Open**, rồi chọn **Done** khi Figma nhập xong. Bạn cũng có thể kéo tệp vào trang danh sách tệp.
4. Mở bản vừa nhập trong Figma Design để xem các khung giao diện hoặc chỉnh sửa.

Thử mở [F01 — Trang chủ](Hinh_6_01_F01_Trang_chu.fig) trước.

[Hướng dẫn nhập tệp của Figma](https://help.figma.com/hc/en-us/articles/360041003114-Import-files-to-the-file-browser)
