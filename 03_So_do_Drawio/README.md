# Mở sơ đồ Draw.io

1. Tại trang GitHub CIV-01, chọn **Code → Download ZIP** rồi giải nén. Mở thư mục `03_So_do_Drawio` và tìm tệp `.drawio` theo số hình trong báo cáo.
2. Mở [diagrams.net](https://app.diagrams.net/). Nếu ứng dụng hỏi nơi lưu, chọn **Device**.
3. Chọn **File → Open From → Device**, sau đó chọn tệp `.drawio` đã tải. Bạn có thể xem, chỉnh sửa và lưu bản thay đổi dưới dạng `.drawio`. Nếu dùng Draw.io Desktop, mở tệp từ **File → Open**.

Ví dụ, [Hình 4.1 — ERD tổng quan](07_Co_so_du_lieu_ERD/Hinh_4_01_ERD_tong_quan_13_bang.drawio) nằm trong thư mục `07_Co_so_du_lieu_ERD`.

[Hướng dẫn mở sơ đồ của Draw.io](https://www.drawio.com/docs/manual/open-diagram-file/)
